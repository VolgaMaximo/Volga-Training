# VOLGA Training

Внутренняя система обучения и экзамена официантов VOLGA.

## Уже реализовано

- обязательный вводный ролик MILA;
- тест по знаниям блюд;
- проходной балл 85%;
- 5 случайных устных ситуаций с гостем;
- 10 секунд на подготовку;
- автоматический старт 30-секундной записи;
- одна попытка без кнопки пересъёмки;
- камера + микрофон в браузере;
- сохранение устных ответов в Supabase Storage;
- страница `/admin` для просмотра записей.

## Запуск

1. `npm install`
2. Скопировать `.env.example` в `.env.local` и заполнить Supabase URL/key.
3. В Supabase выполнить `supabase/schema.sql`.
4. Создать private bucket `oral-recordings`.
5. Положить готовый ролик MILA в `public/mila-intro.mp4`.
6. `npm run dev`.
